# Projeto Campus Reserve

## O que é?

O sistema tem como objetivo facilitar o gerenciamento e a reserva de salas e laboratórios em instituições de
ensino. A aplicação permitirá consultar espaços disponíveis, visualizar suas características e recursos e
realizar reservas para períodos específicos, evitando conflitos de horário.
O público-alvo será composto por alunos, professores e demais usuários autorizados da instituição. A
solução será disponibilizada por meio de uma aplicação web, com frontend integrado a uma API responsável
pelo gerenciamento dos usuários, espaços e reservas.

### Funcionalidades

1. Cadastro e autenticação de usuários.
2. Cadastro e gerenciamento de salas e laboratórios, incluindo informações como capacidade e
recursos disponíveis.
3. Consulta de salas e laboratórios disponíveis.
4. Realização e cancelamento de reservas, com validação para evitar conflitos de horários.
5. Visualização das reservas realizadas pelo usuário e gerenciamento das reservas pelo sistema

## Estrutura do projeto

Front-End: Angular
Back-End: Java Spring boot
Banco de Dados: PostegreSQL
Autenticação/Autorização: Autenticação baseada em JWT, com controle de acesso às funcionalidades do sistema.
